## Context

Epic: `EPIC-08`. Brief M3 asks for "one map (modular, hard-surface ... generated
blockout geometry)". Under the third pass, the map is generated per round from
the layout (`mechanics.md` §1, G1–G2). The geometry follows `tuning.md` §2's
"The layout" table:

- rooms `room_pitch_studs` apart on the grid, abutting, with no corridors;
- ceilings `room_ceiling_studs` high;
- doorways `doorway_width_studs` × `doorway_height_studs`, centred in the
  shared wall;
- machines at the quadrant slots.

This story turns a `Facility` into a list of part specifications (pure, and
tested) and builds them in the place (impure, and checked in Studio). The walls
are also what the line-of-sight port raycasts against (`architecture.md` §9.6),
so wrong geometry is wrong game rules, not only a wrong look.

Creator Store assets are **not** used (`architecture.md` §10, an operator
question). Materials and lighting are placeholders for M4.

**Which required gate would fail if this story's artifact broke:** `unit` for
the specification. The built place is `D-1`.

## Acceptance criteria

- **AC-1** — Given any facility from a sweep of at least 200 seeds, when
  `Blockout.parts` runs, then every room has a floor and a ceiling spanning its
  cell. Every grid edge between two occupied rooms is a wall with a gap
  exactly `doorway_width_studs` wide and `doorway_height_studs` high at its
  centre **if and only if** a door joins them. Every outer edge of an occupied
  cell is a solid wall.
  *Control:* a builder that leaves a gap on every shared edge must fail on a
  layout with a non-door adjacency.
- **AC-2** — Given the same facilities, when machine anchor specs are read, then
  each machine's anchor sits at `Machines.positionOf` (x, z), and carries the
  machine's id as its name.
- **AC-3** — Given the same facilities, when every pair of solid specs is
  tested, then no two overlap by more than a wall's thickness at a corner. No
  spec lies outside the occupied cells' footprint.
- **AC-4** — Given two machines in one room, when the straight segment between
  them is tested against the wall specs, then it crosses none. Given two
  machines in adjacent rooms **without** a door, then it crosses a wall. This is
  the geometric fact the line-of-sight port relies on.

## Contract

**Modules.**

    src/server/facility/Blockout.luau      -- pure
        export type PartSpec = { name: string, kind: "floor" | "ceiling" | "wall" | "machine",
                                 cframe: { x: number, y: number, z: number },   -- centre; axis-aligned, no rotation
                                 size: { x: number, y: number, z: number } }
        Blockout.parts(facility: Generator.Facility, tuning) -> { PartSpec }
        Blockout.WALL_THICKNESS: number      -- 1 stud; engineering, not tuning
    src/server/facility/BlockoutBuilder.luau  -- impure: Instances under workspace.Facility; Studio-verified

- The room-centre formula is `GEN-002`'s. This module does not restate it; it
  calls `Machines.positionOf` and a shared room-centre helper exported from
  `Machines`.
- The builder anchors every part and sets `CanCollide` on walls, floors and
  ceilings. Machine visuals are `HUD-002`'s. This story places only an anchor
  part, named by machine id, that `HUD-002` decorates on the client.
- The builder replaces the previous facility's folder when a new round starts.

**Oracle partition.**
- AC-1 and AC-2 are **settled** by `tuning.md` §2's geometry.
- AC-3 and AC-4 are **mechanical** geometry checks, with a segment/AABB helper
  written in the test.

## Deferred verifications

**D-1. Studio (the operator).** Start a round with 1 to 4 clients, then check:
- walk every room;
- confirm that every doorway can be passed and no wall can;
- confirm that no machine anchor is inside a wall;
- screenshot the facility from above, with the Explorer's `Facility` folder
  expanded.

Owner: REVIEW.

## Out of scope

- Lighting, materials, props, and the tone of the dark (M4).
- Darkening a room on blackout (`HUD-002`, a client-side lighting change driven
  by `RoundView.dark`).
